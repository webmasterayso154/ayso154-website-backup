# AYSO Region 154 - Creative Engine & Design System Guide
Curated architectural patterns synthesized from elite web galleries and component libraries, optimized for youth sports mobile-first interfaces.

## 1. Curated Full-Site Galleries (Aesthetic & Trend Benchmarks)
* **Godly (godly.website):** Benchmark for bold athletic typography, dark-mode atmospheric radial gradients, and smooth scroll choreography.
* **Awwwards (awwwards.com):** Reference standard for kinetic typography, high-impact hero sections, and fluid page transitions.
* **Minimal Gallery (minimal.gallery):** Layout model for crisp typography, generous whitespace, strict visual hierarchy, and high contrast without clutter.
* **One Page Love (onepagelove.com):** Structural standard for single-page event splash pages where parents need answers within a 3-second scroll journey.

## 2. Component & Micro-Interaction Libraries
* **Unsection & Land-book:** Source for modular Bento-style info grids and high-contrast FAQ accordions.
* **Mobbin:** Mobile-first ergonomics benchmark enforcing 48px touch targets, sticky bottom action bars, and swipeable pill navigation.
* **Aceternity UI & 21st.dev:** Inspiration for glowing card borders, spotlight radial gradients, and animated status badges.
